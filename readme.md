# Тестовое задание REST-сервис для агрегатора онлайн-подписок пользователей

## Описание задачи

Проект реализует REST-сервис для агрегирования данных о подписках пользователей на онлайн-сервисы. Сервис позволяет создавать, изменять, удалять, просматривать записи о подписках, а также считать их общую стоимость за выбранный период с фильтрацией по пользователю и названию подписки.

---

## Требования

1. **CRUD-операции над подписками**  
   Каждая запись о подписке должна содержать:
    - Название сервиса, предоставляющего подписку
    - Стоимость месячной подписки (в рублях)
    - ID пользователя (UUID)
    - Дата начала подписки (месяц и год)
    - Опционально: дата окончания подписки

2. **Финансовый отчёт**  
   HTTP-ручка для подсчёта суммарной стоимости всех подписок за выбранный период с фильтрацией по ID пользователя и названию сервиса.

3. **База данных**  
   Используется PostgreSQL. Для работы предоставляются SQL-миграции.

4. **Логирование**  
   Весь код покрыт логами.

5. **Конфигурация**  
   Вынесены конфигурационные параметры в `.env` или `.yaml`-файл.

6. **Документация**  
   Автоматически генерируется swagger-документация (OpenAPI 3.0) по реализованному API.

7. **Запуск через Docker Compose**  
   Сервис и база данных запускаются с помощью docker-compose.

---

## Примечания

- Проверка существования пользователя не требуется — управление пользователями вне области разработки.
- Стоимость любой подписки — целое число рублей, копейки не учитываются.

---

## Быстрый старт

1. **Склонируйте репозиторий и перейдите в папку проекта:**
    ```
    git clone https://github.com/aleksey3535/tt2
    cd tt2
    ```

2. **Настройте файл окружения `.env` и/или конфигурационный `.yaml`**

3. **Запустите сервис и базу командой:**
    ```
    docker-compose up --build -d
    ```

4. **Миграции БД применяются автоматически при запуске.**
